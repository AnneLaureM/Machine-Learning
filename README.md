# Machine-Learning
This course presents the main Machine Learning algorithms and enables you to implement them.

## Interactive Machine Learning Course

An interactive and visual introduction to modern Machine Learning using Python, Scikit-Learn, Plotly, and Hugging Face Transformers.

This course was developed for engineering students at Centrale Méditerranée and combines theoretical explanations, visual demonstrations, practical experiments, and real-world datasets.

The notebook progressively introduces the major concepts of Machine Learning through hands-on examples and interactive visualizations.

## Learning Objectives

By the end of this course, students should be able to:

* Understand the main Machine Learning paradigms.
* Select an appropriate algorithm for a given problem.
* Train and evaluate predictive models.
* Interpret model outputs and performance metrics.
* Apply clustering and dimensionality reduction techniques.
* Build basic NLP pipelines.
* Understand modern Transformer-based architectures.
* Perform model optimization and fine-tuning.
